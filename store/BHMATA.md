# Από το μηδέν στο Play — όλα τα βήματα με τη σειρά

Γραμμένο για λογαριασμό **ιδιώτη** (όχι εταιρείας/συλλόγου). Κάθε βήμα έχει
από κάτω τι πρέπει να δεις για να ξέρεις ότι πέτυχε.

Χρόνος: **2–3 ώρες δουλειάς** σπαρμένες σε **~3 εβδομάδες**, γιατί μεσολαβεί
υποχρεωτική δοκιμή 14 ημερών που δεν επιταχύνεται με τίποτα.

---

# ΜΕΡΟΣ Α — Πριν αγγίξεις το Play

Τρία πράγματα εδώ είναι **μπλοκαριστικά**. Αν τα προσπεράσεις, θα το
ανακαλύψεις όταν θα είναι στα χέρια κόσμου.

## Α1. Ανέβασε τους κανόνες ασφαλείας ⚠️

**Δεν έχουν ανέβει ποτέ.** Μέχρι να ανέβουν, οι κάτοικοι θα βλέπουν
«δεν επιτρέπεται» σε συναγερμούς, ημερολόγιο, τηλέφωνα, συνομιλίες, ονόματα
δρόμων και στο σπίτι στον χάρτη — και **η ιδιωτικότητα των τηλεφώνων
επιβάλλεται εκεί**, οπότε μέχρι τότε ισχύει η παλιά συμπεριφορά.

```bash
cd firebase
npx firebase login
npx firebase use --add          # διάλεξε o-agios-nektarios-mou
npx firebase deploy --only firestore:rules,firestore:indexes
```

✅ **Πέτυχε όταν:** το τερματικό λέει `Deploy complete!` και στο Firebase
Console → Firestore → Rules η ημερομηνία είναι σημερινή.

## Α2. Δοκίμασε σε αληθινό κινητό ⚠️

Τίποτα από αυτή την εφαρμογή δεν έχει τρέξει σε συσκευή. Όλα έχουν
επαληθευτεί με tests, με τον εξομοιωτή των κανόνων και με renders — ο χάρτης
ειδικά δεν αποδίδεται καθόλου εκτός συσκευής.

Βάλε το τρέχον APK (`dist/agios-nektarios.apk`) και έλεγξε **έξι** πράγματα:

| | Τι να δεις |
|---|---|
| 1 | Σύνδεση με Google — δουλεύει |
| 2 | Ο χάρτης ανοίγει και δείχνει πινέζες |
| 3 | Πάνω αριστερά υπάρχει το **κόκκινο «Έκτακτο»** |
| 4 | Νέα αναφορά με φωτογραφία — ανεβαίνει |
| 5 | Ένας συναγερμός — φτάνει σε δεύτερο κινητό |
| 6 | Έρχεται ειδοποίηση |

> Το στιγμιότυπο που έστειλες **δεν είχε** το κόκκινο «Έκτακτο». Αν λείπει και
> με το τρέχον build, είναι σφάλμα και θέλει διόρθωση **πριν** το ανέβασμα —
> είναι το κουμπί του συναγερμού.

## Α3. Φτιάξε το κλειδί υπογραφής

```bash
keytool -genkeypair -v \
  -keystore keystore/upload.jks \
  -alias agiosnektarios-upload \
  -keyalg RSA -keysize 4096 -validity 10000
```

Κράτα **το αρχείο και τον κωδικό** σε password manager. Είναι το μόνο πράγμα
σε όλη τη διαδικασία που δεν ξαναφτιάχνεται.

Μετά `bash store/secrets.sh` — σου τυπώνει τι μπαίνει σε κάθε GitHub Secret και
ελέγχει ότι όλα στέκουν.

✅ **Πέτυχε όταν:** το script τυπώνει τρία πράσινα ✓.

## Α4. Δημόσιο URL για την πολιτική απορρήτου

Το Play θέλει **σύνδεσμο**, όχι αρχείο.

1. Άνοιξε το `store/privacy-policy.el.md` και βάλε το email σου στο τέλος
2. GitHub → Settings → Pages → Deploy from a branch → `main` / `/docs`
3. Αντίγραψε το αρχείο σε `docs/privacy.md` και κάνε push
4. Το URL γίνεται
   `https://grigoriosdimopoulos.github.io/o-agios-nektarios-mou/privacy`

✅ **Πέτυχε όταν:** ανοίγει σε ανώνυμο παράθυρο.

## Α5. Λογαριασμός δοκιμής για τον ελεγκτή

Η εφαρμογή θέλει σύνδεση. Χωρίς λογαριασμό, ο ελεγκτής βλέπει οθόνη σύνδεσης
και **απορρίπτει**.

Φτιάξε **καινούριο** λογαριασμό μέσα από την εφαρμογή — όχι δικό σου, όχι
διαχειριστή — και σημείωσε email και κωδικό.

# ΜΕΡΟΣ Β — Λογαριασμός προγραμματιστή

## Β1. Εγγραφή

[play.google.com/console](https://play.google.com/console) → **25 δολάρια, μία
φορά**. Ταυτοποίηση με ταυτότητα· παίρνει από ώρες μέχρι δύο μέρες.

Θα σε ρωτήσει **Personal ή Organisation**: διάλεξε **Personal**, εκτός αν
υπάρχει σύλλογος με ΑΦΜ που θέλεις να το κατέχει.

> ⚠️ Το Personal ενεργοποιεί τον κανόνα των **12 δοκιμαστών × 14 ημερών**.
> Με Organisation δεν ισχύει — αλλά θέλει επίσημα στοιχεία νομικού προσώπου.

✅ **Πέτυχε όταν:** μπαίνεις στο Console και βλέπεις **Create app**.

## Β2. Δημιουργία εφαρμογής

**Create app**, και:

| Πεδίο | Τιμή |
|---|---|
| App name | `Άγιος Νεκτάριος` |
| Default language | Ελληνικά (Ελλάδα) |
| App or game | App |
| Free or paid | **Free** ← δεν αλλάζει ποτέ σε paid μετά |
| Declarations | Τσέκαρε και τα δύο |

# ΜΕΡΟΣ Γ — Το ανέβασμα

## Γ1. Χτίσε το bundle

```bash
./gradlew :app:bundleRelease
```

Βγαίνει στο `app/build/outputs/bundle/release/app-release.aab`.

Ή, αν έβαλες τα secrets: `git tag v1.0.77 && git push origin v1.0.77` και το
GitHub Action τα κάνει όλα.

## Γ2. Πρώτο ανέβασμα

**Test and release → Testing → Internal testing → Create new release**

Ανέβασε το `.aab`. Το Play θα προτείνει **Play App Signing** — **δέξου το**.

✅ **Πέτυχε όταν:** βλέπεις `1.0.77 (77)` και καμία κόκκινη προειδοποίηση.

## Γ3. Το SHA-1 στο Firebase ⚠️

**Το βήμα που ξεχνιέται και σπάει τη σύνδεση σε κάθε εγκατεστημένο αντίγραφο.**

**Test and release → Setup → App signing** — εκεί υπάρχουν **δύο** πιστοποιητικά:

- *App signing key certificate* — της Google
- *Upload key certificate* — το δικό σου

Πάρε το **SHA-1 και το SHA-256 και από τα δύο** (τέσσερα συνολικά) και βάλ' τα:
**Firebase Console → Project settings → η εφαρμογή Android → Add fingerprint**.

Μετά κατέβασε ξανά το `google-services.json`, αντικατέστησε το υπάρχον,
ξαναχτίσε και ξαναανέβασε.

✅ **Πέτυχε όταν:** το «Συνέχεια με Google» δουλεύει σε κινητό που κατέβασε την
εφαρμογή **από το Play**, όχι με sideload.

## Γ4. Δοκιμαστές

**Internal testing → Testers → Create email list** — βάλε τα emails που θα
μαζέψεις με το μήνυμα του `store/minyma-oikistes.md`.

Αντίγραψε τον **Copy link** και στείλ' τον. Κάθε άτομο πρέπει να τον ανοίξει,
να πατήσει *Become a tester*, και μετά να εγκαταστήσει.

✅ **Πέτυχε όταν:** τουλάχιστον **12 άτομα** την έχουν εγκατεστημένη.
**Από εδώ αρχίζουν οι 14 μέρες.**

## Δ2. Store settings

| Πεδίο | Τιμή |
|---|---|
| App category | Κοινωνικά |
| Tags | χωριό, κοινότητα, τοπικά νέα, χάρτης |
| Email | το email σου (φαίνεται δημόσια) |
| Phone / Website | άφησέ τα κενά |

## Δ3. App content — τα ερωτηματολόγια

**Policy → App content.** Οι απαντήσεις είναι στο `store/PLAY-STORE.md` §8,
συμπληρωμένες από τον κώδικα. Με τη σειρά:

1. **Privacy policy** → το URL από το Α4
2. **App access** → *Some functionality restricted* + ο λογαριασμός από το Α5
3. **Ads** → Όχι
4. **Content rating** → ερωτηματολόγιο, κατηγορία *Social*
5. **Target audience** → **18+**, δεν απευθύνεται σε παιδιά
6. **Data safety** → ο πίνακας του §8.6 — *Shared* = **Όχι** παντού
7. **Government apps / Financial / Health** → Όχι σε όλα

✅ **Πέτυχε όταν:** κάθε γραμμή στο App content έχει πράσινο ✓.

# ΜΕΡΟΣ Ε — Παραγωγή

## Ε1. Περίμενε

Οι 14 μέρες πρέπει να **κυλήσουν** με 12+ δοκιμαστές μέσα. Αν κάποιος
απεγκαταστήσει και πέσεις κάτω από 12, ο μετρητής **σταματάει**. Γι' αυτό 15.

## Ε2. Αίτηση για παραγωγή

Θα εμφανιστεί κουμπί **Apply for production**. Θα σε ρωτήσει πώς έτρεξε η
δοκιμή — γράψε αληθινά τι βρήκατε και τι διορθώθηκε.

## Ε3. Production release

**Production → Create new release** → το ίδιο `.aab` → **Send for review**.

Πρώτος έλεγχος: **1–7 μέρες**.

# Τι πάει στραβά συνήθως

| Σύμπτωμα | Αιτία |
|---|---|
| «Συνέχεια με Google» αποτυγχάνει | Λείπει SHA-1 του **app signing key** (Γ3) |
| Απόρριψη: «could not access» | Δεν δόθηκε λογαριασμός δοκιμής (Α5) |
| `Version code 1 has already been used` | Ρηχό checkout· το Action το έχει λύσει |
| «Δεν επιτρέπεται» παντού στην εφαρμογή | Δεν ανέβηκαν οι κανόνες (Α1) |
| Data safety «incomplete» | Ξέχασες *Data deletion* — ναι, μέσα από την εφαρμογή |
